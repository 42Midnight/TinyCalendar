# TinyCalendar — 产品需求文档 (PRD)

> 版本：v0.1 | 日期：2026-07-29 | 状态：已发布

---

## 1. 产品定位

### 1.1 一句话介绍

**TinyCalendar** 是一款面向个人用户的轻量级 Windows 桌面日历记事软件——安装包不到 10MB，数据完全本地存储，无需网络即可使用。

### 1.2 产品愿景

在日历软件日趋臃肿、动辄几百 MB 且强制联网的今天，TinyCalendar 回归日历的本质：**快速查看日期 + 简单记录事件**。不为团队协作设计，不为云同步妥协——只为一个人的日程管理做到极致。

### 1.3 核心价值主张

| 维度 | 承诺 |
|---|---|
| **轻量** | 安装包 < 10MB，内存占用 < 50MB，启动 < 2秒 |
| **隐私** | 数据存储在本地 SQLite，不上传任何服务器 |
| **离线** | 无需网络连接，所有功能完全可用 |
| **高效** | 全局快捷键一键唤出，三视图快速切换 |
| **原生** | Windows 原生通知、系统托盘、开机自启 |

### 1.4 产品类型

- **类别**：桌面日历 / 个人记事工具
- **平台**：Windows 10 1809+ / Windows 11
- **分发**：NSIS 安装包（.exe）、绿色便携版
- **盈利模式**：完全免费、开源（MIT 协议）

## 2. 用户画像

### 2.1 目标用户

| 用户群 | 典型场景 | 核心需求 |
|---|---|---|
| **学生** | 记录考试日期、课程表、作业截止日期 | 按周查看课表、用颜色区分科目、设置考试提醒 |
| **上班族** | 记录会议、面试、约会、日常备忘 | 快速查看某天安排、按分类筛选、全局快捷键呼出 |
| **自由职业者** | 管理多个项目的截止日期 | 多日历切换、搜索历史记录 |
| **普通用户** | 生日提醒、日常备忘 | 简单易用、数据可备份迁移 |

### 2.2 不服务的用户

- 需要团队共享日历和协作编辑的用户 → 请使用 Google Calendar / 飞书日历
- 需要跨设备（手机+电脑）同步的用户 → 请使用 Outlook / Apple Calendar
- 需要与他人共享日程安排的用户 → 请使用 Calendly

## 3. 市场定位与竞品对比

### 3.1 竞品分析

| 产品 | 安装包大小 | 离线可用 | 内存占用 | 开源 |
|---|---|---|---|---|
| **TinyCalendar** | ~8MB | ✅ | ~40MB | ✅ MIT |
| Windows 自带日历 | 系统内置 | ❌ 需要 Microsoft 账号 | ~150MB | ❌ |
| Google Calendar (Web) | N/A | ❌ | ~300MB (浏览器) | ❌ |
| Notion Calendar | ~200MB | ❌ | ~400MB | ❌ |
| 桌面日历 (国产) | ~50MB | 部分 | ~200MB | ❌ |

### 3.2 差异化优势

1. **极致轻量**：Tauri 框架实现，体积是 Electron 竞品的 1/20
2. **完全离线**：不依赖任何网络服务，数据完全由用户控制
3. **开源透明**：代码完全公开，用户可以审计、修改、自行构建
4. **原生体验**：Windows 原生通知、系统托盘、全局快捷键，类原生性能

## 8. 约束与假设

### 约束
- 仅支持 Windows 平台（Tauri 理论上可跨平台，但当前不投入 macOS/Linux 适配）
- 使用 MSVC 工具链编译（Windows 原生）
- 数据库使用 SQLite（不接受其他数据库方案）

### 假设
- 用户拥有一台运行 Windows 10 1809+ 或 Windows 11 的电脑
- 用户不需要多设备同步
- 用户接受通过 JSON 文件手动备份/迁移数据
- WebView2 运行时已安装（Windows 10 1809+ 和 Windows 11 内置）
