# TinyCalendar — 需求规格说明书

> 版本：v0.1 | 日期：2026-06-21 | 状态：草案待审查

---

## 1. 项目概述

### 1.1 项目名称
**TinyCalendar** — 轻量级 Windows 桌面日历记事软件

### 1.2 项目定位
一款面向个人用户的轻量级 Windows 桌面日历应用，核心解决"日历查看 + 事件记录"的日常需求。不做大而全的团队协作日历，聚焦个人场景：考试时间、见面安排、课表管理、日常备忘。

### 1.3 核心目标
- 安装包小（目标 < 10MB），启动快，内存占用低
- 本地存储，无需网络，数据完全私有
- 快速查询某天/某周/某月的记录
- 支持事件分类管理，一目了然

---

## 2. 用户画像

- **学生**：记录考试时间、课程表、作业截止日期
- **上班族**：记录会议、面试、约会、日常备忘
- **任何需要简单日历记事的 Windows 用户**

## 3. 功能需求

### 3.1 P0 — 核心功能（MVP 必须实现）

| 编号 | 功能 | 描述 |
|---|---|---|
| F01 | 日历月视图 | 显示月历网格，可切换月份，今日高亮 |
| F02 | 日历周视图 | 周历视图，按小时分格，适合查看课表/日程 |
| F03 | 日历日视图 | 日视图，展示当日所有事件，时间线布局 |
| F04 | 添加事件 | 创建事件：标题、日期、时间（可选）、分类、备注 |
| F05 | 编辑事件 | 修改已有事件的所有字段 |
| F06 | 删除事件 | 删除事件（含确认操作） |
| F07 | 事件列表 | 在月视图中点击某天，展示该日所有事件列表 |
| F08 | 事件分类 | 预设分类（考试、见面、课表、工作、个人、其他），支持颜色标记 |
| F09 | 本地存储 | 所有数据存入 SQLite，启动时自动加载 |

### 3.2 P1 — 重要功能（v1.0 发布时应有）

| 编号 | 功能 | 描述 |
|---|---|---|
| F10 | 关键词搜索 | 按标题/备注搜索事件，搜索结果按日期排列 |
| F11 | 日期范围查询 | 筛选某段时间内的事件列表 |
| F12 | 分类筛选 | 按事件分类过滤显示 |
| F13 | 系统托盘 | 最小化到系统托盘，后台运行 |
| F14 | 全局快捷键 | 自定义快捷键，后台运行时一键唤出窗口（默认 `Ctrl+Shift+C`） |
| F15 | 事件提醒 | 到期前弹出 Windows 原生通知 |
| F16 | 重复事件 | 支持每日/每周/每月/每年重复规则 |
| F17 | 数据导出 | 导出为 JSON 格式，可备份迁移 |
| F18 | 主题色切换 | 支持浅色/深色主题，可跟随系统自动切换 |

### 3.3 P2 — 增强功能（后续迭代）

| 编号 | 功能 | 描述 |
|---|---|---|
| F19 | 农历显示 | 月视图中显示农历日期和节气 |
| F20 | 节假日 | 内置中国法定节假日数据 |
| F21 | 数据导入 | 从 JSON 文件导入数据 |
| F22 | 字体大小 | 用户可调节界面字体大小 |
| F23 | 开机自启 | 可选的系统启动项 |

## 4. 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NF01 | 安装包大小 | < 10MB |
| NF02 | 内存占用（空闲） | < 50MB |
| NF03 | 启动时间 | < 2秒 |
| NF04 | 数据容量 | 支持 10000+ 条事件不卡顿 |
| NF05 | 离线运行 | 完全离线，无需网络连接 |
| NF06 | Windows 版本 | 支持 Windows 10 1809+ 和 Windows 11 |
| NF07 | 多实例保护 | 同一时间只允许运行一个实例 |
| NF08 | 数据安全 | 异常退出时不损坏数据库文件 |
