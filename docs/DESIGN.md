# TinyCalendar — UI 设计规范

> 版本：v0.1 | 日期：2026-07-29 | 状态：已发布

---

## 1. 设计原则

### 1.1 核心理念

| 原则 | 说明 |
|---|---|
| **轻量感** | 大量留白、细线条、低视觉重量，不与内容争抢注意力 |
| **一目了然** | 日历是信息密集型界面，设计服务于信息可读性而非装饰性 |
| **响应即时** | 所有交互动画 ≤ 150ms，不拖慢操作节奏 |
| **一致性** | 同类元素相同的圆角、间距、颜色语义，降低用户认知负荷 |
| **尊重系统** | 支持浅色/深色/跟随系统，融入用户的桌面环境 |

### 1.2 不做什么

- ❌ 不使用渐变背景、阴影堆叠、玻璃拟态等重装饰效果
- ❌ 不在日历视图中有超过 100ms 的过渡动画
- ❌ 不使用 emoji 作为 UI 元素（仅事件标题中允许用户自由使用）
- ❌ 不在主界面使用超过 14px 的正文字号

## 2. 色彩系统

### 2.1 浅色主题 (Light)

| Token | HEX | 用途 |
|---|---|---|
| `--bg-primary` | `#ffffff` | 主背景（日历网格、面板） |
| `--bg-secondary` | `#f9fafb` | 次背景（侧边栏、标题栏） |
| `--bg-tertiary` | `#f3f4f6` | 三级背景（按钮 hover、分割区域） |
| `--text-primary` | `#111827` | 主文字 |
| `--text-secondary` | `#6b7280` | 次要文字（标签、辅助信息） |
| `--text-tertiary` | `#9ca3af` | 占位符、禁用态文字 |
| `--border` | `#e5e7eb` | 边框 |
| `--border-light` | `#f3f4f6` | 浅边框（内部分隔） |
| `--accent` | `#3b82f6` | 主题色（选中、今日、主按钮） |
| `--accent-hover` | `#2563eb` | 主题色 hover 态 |
| `--hover` | `#f3f4f6` | 通用 hover 背景 |

### 2.2 深色主题 (Dark)

| Token | HEX | 用途 |
|---|---|---|
| `--bg-primary` | `#1a1a2e` | 主背景 |
| `--bg-secondary` | `#16162a` | 次背景（侧边栏） |
| `--bg-tertiary` | `#2a2a3e` | 三级背景（卡片、按钮） |
| `--text-primary` | `#e5e7eb` | 主文字 |
| `--text-secondary` | `#9ca3af` | 次要文字 |
| `--text-tertiary` | `#6b7280` | 占位符 |
| `--border` | `#2a2a3e` | 边框 |
| `--border-light` | `#222236` | 浅边框 |
| `--accent` | `#60a5fa` | 主题色 |
| `--accent-hover` | `#3b82f6` | 主题色 hover 态 |
| `--hover` | `#2a2a3e` | 通用 hover 背景 |

### 2.3 分类颜色（事件标签）

| 分类 | HEX | 适用场景 |
|---|---|---|
| 考试 | `#EF4444` (红色) | 紧急、截止日期 |
| 见面 | `#F59E0B` (橙色) | 社交、约会 |
| 课表 | `#3B82F6` (蓝色) | 课程、学习 |
| 工作 | `#8B5CF6` (紫色) | 会议、任务 |
| 个人 | `#10B981` (绿色) | 生活、健康 |
| 其他 | `#6B7280` (灰色) | 未归类 |

用户可自定义分类名称和颜色，以上为预设默认值。

### 2.4 颜色使用规则

- 事件卡片使用左侧色条（2px 宽）展示分类颜色，卡片主体保持背景色
- 今日日期使用主题色 (`--accent`) 实心圆背景 + 白色文字
- 选中日期使用主题色 15% 透明度的浅色背景
- 当日事件小圆点在月视图上显示分类颜色，直径 5px
- 非当前月日期文字使用 `--text-tertiary`，降低对比度

## 3. 字体与排版

### 3.1 字体族

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Microsoft YaHei", "Helvetica Neue",
  Helvetica, Arial, sans-serif;
```

- 英文优先使用系统原生字体（Segoe UI on Windows）
- 中文回退到苹方（macOS）/ 微软雅黑（Windows）

### 3.2 字号阶梯

| 用途 | 字号 | 行高 | 字重 |
|---|---|---|---|
| 标题栏 | 13px | 1.5 | 500 |
| 日历日期数字 | 13px | 1 | 400 |
| 侧边栏分类标签 | 13px | 1.5 | 400 |
| 事件卡片标题 | 13px | 1.4 | 500 |
| 事件卡片时间 | 12px | 1.4 | 400 |
| 正文（表单、备注） | 13px | 1.5 | 400 |
| 辅助文字 | 11px | 1.5 | 400 |

用户可通过设置切换字体大小：小号（13px）、中号（14px 默认）、大号（16px）。

### 3.3 文本截断

- 事件标题超过卡片宽度时截断，末尾加省略号 (`text-overflow: ellipsis`)
- 月视图日期格内事件圆点最多显示 3 个，超出显示 "+N"
- 搜索结果的备注字段截断为单行

## 4. 间距与布局

### 4.1 间距系统

采用 4px 基准间距体系：

| Token 名称 | 值 | 用途 |
|---|---|---|
| `space-1` | 4px | 紧密关联元素（标签组、图标+文字） |
| `space-2` | 8px | 组件内元素间距（按钮内边距、表单字段） |
| `space-3` | 12px | 区块内间距（卡片 padding） |
| `space-4` | 16px | 组件间距（侧边栏与主区域） |
| `space-6` | 24px | 大区块间距 |

### 4.2 圆角

| 元素 | 圆角 | 说明 |
|---|---|---|
| 窗口 | 0 | 无边框窗口不自带圆角（由 Windows 系统决定） |
| 卡片/面板 | `--radius: 8px` | 事件卡片、设置面板、弹窗 |
| 按钮/输入框/小元素 | `--radius-sm: 6px` | 保持统一精致感 |
| 日期格 | 6px (hover), 50% (today) | 今日圆形高亮 |

### 4.3 布局结构

```
┌─────────────────────────────────────────────┐
│  TitleBar (h: 40px)                          │
├──────────┬──────────────────────────────────┤
│ Sidebar  │  CalendarHeader (h: 48px)        │
│ (w: 220) │  ┌────────────────────────────┐  │
│          │  │                            │  │
│          │  │   Calendar View             │  │
│          │  │   (flex-1)                 │  │
│          │  │                            │  │
│          │  └────────────────────────────┘  │
│          │  EventPanel (w: 260)             │
│          │  (可折叠)                         │
└──────────┴──────────────────────────────────┘
```

- 最小窗口尺寸：720 × 480
- 默认窗口尺寸：960 × 680
- 侧边栏宽度：220px
- 事件面板宽度：260px
- 标题栏高度：40px
- 日历头部高度：48px

## 5. 组件设计规范

### 5.1 日历月视图 (MonthView)

- 7 列 × 6 行等分网格，无外边距
- 每格高度 `(容器高度 - 表头) / 6`，宽度 `容器宽度 / 7`
- 表头行显示"日 一 二 三 四 五 六"，字体 `--text-secondary`
- 日期数字在格内左上角，padding: 4px 8px
- 今日：实心圆形背景 `--accent` + 白色文字
- 选中日：`--accent` 15% 透明度背景 + 2px 左边框强调
- 非当月日期：字体色 `--text-tertiary`
- 事件缩略点：日期数字下方，水平排列，最多 3 个 + "+N"

### 5.2 日历周视图 (WeekView)

- 7 列，左侧时间标注 (00:00 ~ 23:00)
- 每列宽度等分剩余空间，每小时高度 60px
- 当前时间红线指示器
- 事件以色块覆盖时段，高度 = 时长(小时) × 60px
- 色块左侧 3px 分类颜色条
- 色块内部显示标题 + 时间范围

### 5.3 日历日视图 (DayView)

- 单列时间线，左侧时间标注
- 每小时高度 80px（比周视图更大，方便查看详情）
- 事件色块同上
- 全天事件显示在顶部"全天"区域

### 5.4 事件卡片 (EventCard)

```
┌──┬──────────────────────────────┐
│▐▐│ 标题（粗体 13px）             │
│  │ 14:00 - 15:30  分类标签      │
│  │ 备注摘要（单行截断）          │
└──┴──────────────────────────────┘
```

- 左侧 2px 分类颜色竖条
- padding: 8px 12px
- 背景：`--bg-primary`，圆角 `--radius-sm`
- hover: 背景变为 `--hover`，鼠标变为 pointer
- 边框：`1px solid var(--border)`

### 5.5 按钮 (Button)

提供 5 种变体：

| 变体 | 使用场景 |
|---|---|
| `btn-primary` | 主要操作（保存、确认） |
| `btn-secondary` | 次要操作（取消、关闭） |
| `btn-ghost` | 工具栏图标按钮、侧边栏操作 |
| `btn-icon` | 纯图标按钮（32 × 32px 最小热区） |
| `btn-danger` | 删除等破坏性操作 |

高度统一 32px，padding: 6px 14px，字重 500。

### 5.6 输入框 (Input)

```
┌──────────────────────────────────┐
│ 请输入标题...          13px 400 │
└──────────────────────────────────┘
```

- 高度 36px，padding: 8px 12px
- border: `1px solid var(--border)`，圆角 `--radius-sm`
- focus: border 变为 `--accent` + `0 0 0 2px rgba(59,130,246,0.15)` 阴影
- placeholder: `--text-tertiary`
- textarea 最小高度 60px，可拖拽调整

### 5.7 模态框 (Modal)

- 居中显示，背景遮罩 `rgba(0,0,0,0.3)`
- 内容区域背景 `--bg-primary`，圆角 12px
- 最大宽度 520px，最大高度 80vh
- 标题栏 44px + 内容区域 flex-1 + 底部按钮栏 52px
- 动画：fadeIn 150ms ease-out
- 点击遮罩关闭（事件编辑器除外，防止误操作丢失数据）

### 5.8 自定义标题栏 (TitleBar)

- 高度 40px，背景 `--bg-secondary`
- 左侧：应用名称（13px，`--text-secondary`）+ 设置齿轮图标
- 右侧：最小化、最大化/还原、关闭三个控制按钮
- 按钮热区：40 × 32px，hover 背景 `--hover`
- 关闭按钮 hover：红色背景 `#ef4444`
- 拖拽区域：`data-tauri-drag-region` 属性标记

## 6. 动画与过渡

### 6.1 过渡规范

| 交互 | 时长 | 缓动 |
|---|---|---|
| 按钮/链接 hover | 150ms | ease |
| 输入框 focus | 150ms | ease |
| 模态框打开 | 150ms | ease-out |
| 模态框关闭 | 100ms | ease-in |
| 侧边栏折叠 | 200ms | ease-in-out |
| 视图切换 | 0ms（直接切换） | — |

### 6.2 不做动画的地方

- 日历翻页（月/周切换）：直接更新，无过渡。日历是信息密集型界面，过渡动画会增加认知延迟
- 搜索结果展开：即时显示
- 主题切换：瞬时切换（非渐变动画）

## 7. 自定义滚动条

```css
::-webkit-scrollbar          → width: 4px
::-webkit-scrollbar-track    → background: transparent
::-webkit-scrollbar-thumb    → background: var(--text-tertiary)
::-webkit-scrollbar-thumb:hover → background: var(--text-secondary)
```

- 滚动条始终窄（4px），不占用过多空间
- 无滚动条轨道背景，视觉上更轻量
- 滑块圆角 2px

## 8. 交互规范

### 8.1 选择行为

- **单击日期**：选中该日期，右侧事件面板更新为该日事件列表
- **双击日期**：弹出该日的详细视图（DayDetail 模态框），展示该日所有事件的完整信息
- **单击事件**：打开事件编辑器（编辑模式）
- **双击事件**：打开事件编辑器（编辑模式）
- **右键事件**：待实现（计划中：上下文菜单含"删除""复制""改分类"）

### 8.2 键盘快捷键

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Shift+C` | 全局唤出/隐藏窗口（可自定义） |
| `←` / `→` | 选中日期左右移动（日视图） |
| `↑` / `↓` | 选中日期上下移动（日视图，上一行/下一行 = 7天） |
| `Space` | 跳转到今天 |
| `Ctrl+N` | 新建事件 |
| `Esc` | 关闭当前弹窗 |

### 8.3 拖拽

- 侧边栏分类列表支持拖拽排序
- 拖拽手柄为分类项左侧的六点图标（grip）
- 拖拽时显示蓝色指示线（2px `--accent`）
- 使用 HTML5 Drag and Drop API 实现

## 9. 无障碍

### 9.1 当前状态

- 用户可通过 Tab 键在表单中导航
- 模态框打开时焦点自动移入，Esc 键关闭
- 按钮有明确的 hover/focus 视觉反馈

### 9.2 待改进（P2）

- 完整的键盘操作支持（无需鼠标即可完成所有操作）
- 屏幕阅读器（Narrator）支持
- 高对比度模式适配
- ARIA 标签补充

## 10. 设计资源

本项目的所有 UI 通过 Tailwind CSS + CSS 自定义属性实现，无需设计工具导出。主题变量定义在 `src/styles/index.css` 的 `@layer base` 中。

修改主题色只需覆盖 CSS 自定义属性；修改组件样式在各组件的 className 或用 `@layer components` 中的类。
